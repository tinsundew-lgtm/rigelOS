## Команды на завтра

```powershell
# 0. Проверить всё, ничего не собирая (работает в Windows, Git Bash)
bash scripts/verify-all.sh
```

```powershell
# Способ 1 — без своего Linux: залить проект на GitHub,
# Actions → «Сборка ISO Rigel» → Run workflow → скачать артефакт rigel-iso
```

```powershell
# Способ 2 — Docker Desktop (Windows), ISO окажется в out\
pwsh -File scripts\build-in-docker.ps1
```

```bash
# Способ 3 — когда Linux заработает (или с живой флешки Arch)
sudo scripts/build-iso.sh
```

Запись на флешку из Windows: **Rufus** → ISO → GPT/UEFI → режим **«DD-образ»**.

## Сколько это занимает времени

| Этап | Время | Ваше участие |
|---|---|---|
| Дописать профиль и Plasma (моя часть) | ~40–60 мин | нет |
| Сборка в GitHub Actions | 20–35 мин + скачивание ISO 1.5 ГиБ (5–30 мин по скорости интернета) | ~5 мин (нажать кнопку и скачать) |
| Сборка в Docker на вашем ПК | первый запуск 10–15 мин (образ + пакеты), затем 15–30 мин на 4 ядрах / 30–50 мин на слабом ноутбуке | ~0 |
| Сборка на Arch | 15–30 мин | ~0 |
| Запись на флешку (4 ГБ) | 3–8 мин | ~2 мин |
| Первая загрузка и проверка | 2–5 мин | вы |

**Итого реально: 1–1.5 часа**, если идти через GitHub Actions (своего Linux не надо вообще).
Если собирать в Docker — примерно столько же, но без ожидания скачивания.

## Если Linux «сломался» совсем

- Проект живёт в Windows-папке — он не пострадал.
- Собрать ISO можно с **живой флешки обычного Arch Linux** (загрузиться с неё, подключить
  интернет, скачать проект, `sudo scripts/build-iso.sh`) — ваша сломанная система не затрагивается.
- Либо вообще без Linux: GitHub Actions или Docker Desktop.
- Если хотите, в следующий раз помогу разобраться, что именно сломалось (не грузится?
  чёрный экран? GRUB?) — по симптомам подскажу, как починить или как вытащить данные.
